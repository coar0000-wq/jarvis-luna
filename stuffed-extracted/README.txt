# Stuffed Dog Digital — static recreation

This is a clean-room static recreation based on the publicly visible structure/content of the Stuffed Dog Digital homepage.

Files:
- index.html
- style.css
- script.js
- assets/dog.png

Run:
1. Keep the folder structure intact.
2. Open index.html directly in a browser, or run a local server:
   python -m http.server 8000
3. Visit http://localhost:8000

The contact form is intentionally frontend-only and opens the user's mail client using mailto.
Replace the mailto address or connect a real form backend before production use.
