JARVIS LUNA · Obsidian ↔ GitHub 실제 동기화 설치

설정된 Obsidian 볼트 경로: C:\Users\Desktop\Obsidian
동기화 대상 폴더: C:\Users\Desktop\Obsidian\JARVIS_LUNA
동기화 간격: 5분

가장 쉬운 설치 방법

1. 이 설치 패키지의 automation 폴더를 엽니다.
2. install_and_start_obsidian_sync.bat을 더블클릭합니다.
3. 검은 창에 [OK] 설치와 첫 동기화가 완료되었습니다.라는 메시지가 표시될 때까지 기다립니다.

설치 파일은 다음 작업을 자동으로 수행합니다.
- C:\Users\Desktop\Claude\Projects\kms\jarvis-luna 에 최신 GitHub 저장소를 내려받습니다.
- 개인 Obsidian 설정을 새 저장소에 복사합니다.
- 첫 Obsidian ↔ GitHub 동기화를 실행합니다.
- Windows 작업 스케줄러에 5분 자동 동기화 작업을 등록합니다.

주의:
- Git과 Python 3이 설치되어 있어야 합니다.
- GitHub에 로그인된 Git 환경이 필요합니다. 첫 동기화에서 GitHub 푸시 권한이 없으면 검은 창의 오류 또는 automation\logs\obsidian_sync.log 내용을 보내주세요.
- 동기화는 Obsidian 볼트 전체가 아니라 JARVIS_LUNA 폴더만 관리합니다.
- 개인 볼트 경로가 들어 있는 obsidian_sync_config.json은 GitHub에 올라가지 않습니다.
