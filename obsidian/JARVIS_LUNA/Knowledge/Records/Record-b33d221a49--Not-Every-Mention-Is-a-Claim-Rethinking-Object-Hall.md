Not Every Mention Is a Claim: Rethinking Object Hallucination Detection in Vision-Language Models
Object hallucination in vision-language models (VLMs) is usually measured by checking each object a caption names against the image. Most benchmarks and detectors alike treat every object mention as a claim that the object is present.
