# Claude Skills Core Four

영상의 공개 요약에서 확인된 네 가지 핵심 범주를 JARVIS용 Markdown 스킬로 정리한 허브다. 원영상의 공개 페이지에서는 정확한 제3자 skill slug가 확인되지 않았으므로, 아래 이름은 영상 범주를 기준으로 만든 JARVIS 문서명이다.

| 스킬 | 역할 |
|---|---|
| [[Skill-Claude-Token-Saving]] | 컨텍스트 중복과 불필요한 읽기를 줄인다. |
| [[Skill-Claude-Design]] | 대시보드·문서의 정보 구조와 모바일 가독성을 설계한다. |
| [[Skill-Claude-Planning]] | 목표·의존성·완료 기준·검증 순서를 먼저 고정한다. |
| [[Skill-Claude-Search]] | 원문을 확인하고 출처·불확실성을 보존한다. |
