## 📊 템플릿 섹션별 작성 가이드

### 1. Core Concept 섹션
```markdown
**[그래프 제목]: [한 줄 설명]**
- Focus: [주된 학습 영역]
- Level: 초보자 → 중급 → 고급
- Application: [실제 적용 분야]
- Goal: [학습/구현 목표]
- Year: [현재/발표 연도]
- Importance: [중요도/필요성]
```

**작성 팁**:
- "Focus"는 명확하고 구체적으로
- "Level"은 대상 청중 기준으로
- "Application"은 실제 사용 사례 중심

### 2. 주요 섹션
```markdown
### [[Topic Name]]

**정의**:
[[Concept]]:
- [[Point 1]]: 간단한 설명
- [[Point 2]]: 간단한 설명

**특징**:
[[Key Characteristics]]:
- [[Feature 1]]: 설명
- [[Feature 2]]: 설명
```

**작성 팁**:
- 3-5개의 핵심 포인트만 선택
- 각 포인트는 한 문장 정도로 간결하게
- `[[Double Bracket]]` 형식으로 Obsidian 링크 생성

### 3. YouTube 자료 섹션
```markdown
1. [[Video-Slug]] - "[정확한 제목]"
   - **Channel**: [이름] ([구독자])
   - **Duration**: [시간]분 [초]초
   - **Upload**: [언제]
   - **Views**: [조회수]
   - **Focus**: [비디오의 주요 내용]
   - **Difficulty**: [초보자/중급/고급]
   - **Key Sections**:
     - [[Topic 1]]: 설명
     - [[Topic 2]]: 설명
```

**작성 팁**:
- Channel 이름과 구독자 수는 정확하게
- Duration은 총 시간으로 (예: 10분 30초)
- Views는 추출 당시 수치 (대략 단위: 천, 만)
- Key Sections는 3-4개 정도로 제한
- Difficulty는 일관되게 (초보자/중급/고급)

### 4. 메타데이터 푸터
```markdown
**📌 최종 업데이트**: YYYY년 M월 D일
**📌 노드**: [개수]+ (Claude가 자동 계산)
**📌 상태**: 활성
**📌 대상**: [대상 청중]
```

**작성 팁**:
- "최종 업데이트"는 생성일로 설정
- "노드"는 추정치 (예: 100+, 150+)
- "상태"는 항상 "활성"으로 시작
- "대상"은 구체적으로 (예: AI 초보자, 엔터프라이즈 리더)

## 📞 문제 해결

### Q: 노드 수를 어떻게 계산하나?
A: 
```
기본 구성: ~30 노드
섹션당: ~10-15 노드
YouTube 자료 1개당: ~8-10 노드
따라서: 30 + (섹션수×12) + (비디오수×9) ≈ 총 노드

예: 3개 섹션 + 5개 비디오
    30 + (3×12) + (5×9) = 30 + 36 + 45 = 111 노드
    → "110+" 또는 "115+" 표기
```
