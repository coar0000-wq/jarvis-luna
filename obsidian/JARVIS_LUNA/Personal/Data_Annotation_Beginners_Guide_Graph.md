## What is Data Annotation?

### [[Data Annotation Foundation]]

**핵심 정의**:
[[Data Annotation]]은 머신러닝 모델을 훈련시키기 위해 원본 데이터에 레이블을 붙이는 과정입니다.

**AI와 ML의 척추**:
- [[Backbone of AI]]: AI/ML 개발의 핵심
- [[Essential Process]]: 모든 AI 프로젝트에 필수
- [[Quality Critical]]: 데이터 품질 = 모델 성능
- [[Foundation]]: 전체 시스템의 기초

#### 왜 데이터 주석이 필요한가?

[[Why Data Annotation Matters]]:
- [[Supervised Learning]]: 지도학습 모델 훈련
- [[Training Data]]: 모델이 배우는 방식
- [[Pattern Recognition]]: 패턴 인식을 위한 예시
- [[AI Accuracy]]: AI 정확도를 결정
- [[Industry Standard]]: 모든 산업에서 필수
