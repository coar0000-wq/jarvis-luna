#### 1️⃣ EHR Management & Clinical Documentation ⭐⭐⭐⭐⭐

| 항목 | 설명 |
|------|------|
| **기능** | 전자의무기록 관리 & 문서화 |
| **중요도** | 최상위 (모든 직종 필수) |
| **효율** | 시간 20.4% 단축 |
| **자동화** | AI 스크라이브 지원 |

**핵심 능력:**
```
1. 기본 EHR 시스템 조작
   ├─ 환자 정보 입력
   ├─ 진료 기록 작성
   └─ 약물 처방 관리

2. AI 임상 문서화
   ├─ 음성-텍스트 변환
   ├─ 자동 노트 생성
   └─ 규정 준수 검증

3. 데이터 품질 관리
   ├─ 오류 감지
   ├─ 일관성 검증
   └─ 개인정보 보호
```

**도구 & 시스템:**
- Nuance DAX
- AWS HealthScribe
- Microsoft Azure AI Health
- Bells Documentation Assistant
