## Google Search Basics

[[Google Search]] is the world's most popular search engine that indexes billions of pages and returns results based on user queries and relevance.

## Core Web Vitals

### The Three Main Metrics
[[Google's UX Signals]]:

#### Largest Contentful Paint (LCP)
[[Loading Speed]]:
- [[Target]]: Under 2.5 seconds
- [[What Measures]]: Main content load
- [[Why Important]]: User experience
- [[Optimize]]: Image optimization
- [[Server Response]]: Fast hosting
- [[CSS Optimization]]: Streamline code
- [[JavaScript]]: Reduce impact

#### First Input Delay (FID)
[[Interactivity]]:
- [[Target]]: Under 100 milliseconds
- [[What Measures]]: Response to input
- [[Why Important]]: Feel of responsiveness
- [[JavaScript Threads]]: Break up work
- [[Event Listeners]]: Optimized handlers
- [[User Interactions]]: Click responsiveness
- [[Mobile Impact]]: Especially important

#### Cumulative Layout Shift (CLS)
[[Visual Stability]]:
- [[Target]]: Below 0.1
- [[What Measures]]: Unexpected movements
- [[Why Important]]: User frustration
- [[Ad Placement]]: Stable positioning
- [[Image Dimensions]]: Set heights/widths
- [[Font Loading]]: Stable fonts
- [[Scroll Position]]: Don't shift

### Page Experience Signals
[[Overall UX]]:
- [[Mobile Friendly]]: Works on mobile
- [[No Intrusive Ads]]: Acceptable ads
- [[HTTPS Security]]: Secure connection
- [[Core Web Vitals]]: Performance metrics

### Crawl Budget

- [[Crawl Demand]]: Pages worth crawling
- [[Crawl Delay]]: Time between crawls
- [[URL Parameters]]: Avoid duplicates
- [[Redirect Chains]]: Minimize redirects
- [[Large Files]]: Minimize size

- [[Sitemap Quality]]: Accurate list
- [[Duplicate Content]]: Remove duplicates

### Indexability
[[Getting in Index]]:
- [[No Noindex Tags]]: Allow indexing
- [[No Robots.txt Block]]: Allow crawl
- [[Unique Content]]: Not duplicate
- [[Public URLs]]: Not behind login
- [[Valid HTML]]: Proper code
- [[Mobile Accessible]]: Works on mobile
- [[Content Accessible]]: No JS issues
- [[Meta Tags]]: Proper implementation
- [[Structured Data]]: Schema markup

### Blocking Indexation
[[What Google Can't/Won't Index]]:
- [[Robots.txt Block]]: Crawl forbidden
- [[Noindex Tag]]: Index forbidden
- [[Password Protected]]: Behind login
- [[Duplicate Content]]: Same as elsewhere
- [[Thin Content]]: Too little content
- [[JavaScript Issues]]: Can't render
- [[Nofollow Links]]: Won't follow
- [[ 404 Errors]]: Page not found
- [[Redirect Chains]]: Too many redirects
