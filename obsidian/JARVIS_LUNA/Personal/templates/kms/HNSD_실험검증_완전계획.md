### 2-1-2. 기초 특성 측정 (8/16-8/25)

**Test 1: 이온 전도도 (Impedance 분석)**

```
장비: Hioki LCR 미터 IM3536 또는 Solartron
온도: 실온 (25°C ± 2°C)
주파수: 1 kHz
측정 구성:
- 샘플 2개의 표면에 Pt 전극 부착 (스퍼터링)
- 직렬 임피던스 측정
- 3회 반복 측정 후 평균

계산식:
σ (S/cm) = (L / R × A)
- L: 샘플 두께 (cm)
- R: 저항값 (Ω)
- A: 전극 면적 (cm²)

목표값:
┌─────────────────────┐
│ 1-1: 1.5 mS/cm      │
│ 1-2: 2.5 mS/cm      │
│ 1-3: 5.0 mS/cm      │
│ 1-4: 8.0 mS/cm ✓    │
│ 1-5: 9.0 mS/cm      │
└─────────────────────┘
```

**Test 2: X선 회절 분석 (XRD)**

```
장비: Rigaku MiniFlex 또는 동등 장비
조건:
- Cu Kα 방사선 (λ = 1.54 Å)
- 주사 범위: 10° ~ 80° (2θ)
- 주사 속도: 2°/분
- 스텝: 0.02°

분석 항목:
1. 결정성 계산 (Crystallinity %)
   - FWHM (Full Width Half Maximum) 분석
   - Rietveld 정제화 (refinement)
   - 목표: ≥95% 결정성

2. 격자 상수 변화 측정
   - 도핑 전후 격자 팽창/수축 비교
   - Mg, I⁻ 도핑이 구조에 미치는 영향

3. 불순물 확인
   - 예상 불순물: MgO, LiF, ZrO₂ (코팅층)
   - 량 정량화: < 5% (허용)

기대 결과:
- 도핑된 샘플: 격자 상수 미세 변화 (±0.2%)
- 결정 구조: 유지 (orthorhombic)
- 불순물: 최소화
```

**Test 3: 전자 현미경 분석 (SEM)**

```
장비: JEOL JSM-7100F 또는 동등 장비
배율: 1,000× ~ 100,000×

Test 3-1: 입자 크기 측정
- 저배율 (10,000×): 전체 형태 관찰
- 고배율 (50,000×): 개별 입자 측정
- 샘플당 100개 입자 측정
- 목표: 평균 입자 크기 50-200 nm

Test 3-2: 표면 형태 분석
- 매끈함 정도 평가
- 코팅층 상태 확인
- 응집도 평가

Test 3-3: 에너지 분산 X선 분광 (EDS)
- 원소 구성 확인
- Mg, I, Zr, Al, F 정량분석
- 도핑 정도 검증

기대 결과:
┌──────────────────────────────────┐
│ 샘플 1-4 (최종)                   │
│ - 평균 입자 크기: 120-150 nm      │
│ - Mg 검출: 1.0±0.2 mol%          │
│ - I 검출: 0.5±0.1 mol%           │
│ - Zr 검출: 2.0±0.3 wt%           │
│ - Al/F (코팅): 확인 ✓             │
└──────────────────────────────────┘
```

## 🔄 Phase 2-3: 사이클 수명 테스트 (9/6-9/25)

### 2-3-1. 배터리 셀 제작

**셀 구성:**

```
양극 (Cathode):
- 재료: LiCoO₂ (LCO) 또는 NCM811
- 무게: 50 mg
- 직경: 12 mm
- 형태: 압축된 펠릿

고체전해질 (Electrolyte):
- HNSD 샘플: 150 mg
- 직경: 12 mm
- 압축: 200-300 MPa 프레스
- 두께: 약 2 mm

음극 (Anode):
- 재료: 금속 리튬 (Li)
- 무게: 25 mg
- 크기: 12 mm × 25 mm × 0.5 mm
- 순도: 99.9% 이상

분리막:
- Celgard 2320
- 크기: 20 mm × 40 mm
```

**셀 조립 절차 (Glove Box 내):**

```
Step 1: 양극 준비
- LCO 분말 → 프레스기에서 500 MPa 압축
- 원통형 펠릿 형성 (12mm × 2mm)
- 질량 확인: 50±2 mg

Step 2: 고체전해질 준비
- HNSD 분말 → 몰드에 입력
- 프레스: 250 MPa × 10분
- 두께 확인: 2.0±0.1 mm

Step 3: 계층 쌓기 (Layer Stacking)
순서:
┌─────────────────────┐
│  금속 Li (음극)      │
│  분리막 (Celgard)   │
│  HNSD 전해질        │
│  LCO (양극)         │
│  분리막 (Celgard)   │
└─────────────────────┘

Step 4: 최종 프레스
- 압력: 300 MPa
- 시간: 5분
- 냉각: 실온으로 천천히 냉각

Step 5: 파우치 셀 봉인
- 알루미늄 라미네이트 포장
- 열 밀봉: 300°C, 3초
- 질소 충전: 불활성 분위기
```

**셀 수량:**

```
그룹 A: 기본 성능 (4개)
- HNSD 1-4 (최종 기술): 3개

그룹 B: 고도핑 (3개)
- HNSD 1-5: 2개
- 대조군: 1개

그룹 C: 표면 코팅 비교 (2개)
- Al2O3만: 1개
- Al2O3 + LiF: 1개

그룹 D: 극한 환경용 (1개)

총 10개 셀 + 대비용 5개 셀 = 15개 (여유 포함)
```

### 2-3-2. 초기화 순환 (Formation Cycling)

**목적:** 셀의 안정적인 상태 형성, 초기 손실 제거

```
프로토콜:
온도: 실온 (25°C)
환경: 온도 제어 챔버

1차 충전 (Charge):
- CC (정전류): 0.05C rate까지 충전
  * 용량: ~50-100 mAh/g (LCO 기준)
  * 전류: 50 mA/g × 샘플 무게 = ?
  
예: 양극 50mg LCO 기준
  → 0.05C = 2.5 mA
  
- CV (정전압): 4.2V에서 0.01C까지 유지
- 시간: 약 8-10시간

1차 방전 (Discharge):
- CC: 0.05C rate로 완전 방전
- 종료 전압: 2.5V
- 시간: 약 20시간

2차-3차 순환:
- 0.1C rate로 2회 반복
- 일정성 확인

데이터 기록:
- 충방전 곡선
- 용량
- 효율 (Coulombic Efficiency)
```
