## 🔧 **손실 함수 및 최적화**

### Cross Entropy Loss
```python
def compute_loss(logits, labels):
    exp_logits = exp(logits - max(logits))
    probs = exp_logits / sum(exp_logits)
    loss = -sum(one_hot(labels) * log(probs)) / batch_size
    return loss
```

**특징:**
- 수치적 안정성 (overflow 방지)
- 클래스별 확률 최대화
- 10개 클래스 분류 최적화

### 배치 정규화
```
배치 크기: 32
학습률: 0.001 (Adam 권장)
Momentum: 0.9
Weight decay: 0.0001 (L2 정규화)
```
