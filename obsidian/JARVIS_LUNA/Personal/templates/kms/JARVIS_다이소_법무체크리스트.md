# 【Daiso Dropshipping 법적 검토 체크리스트】

## 【1. 상품 리셀링 법적 기초】

- [ ] ✅ 다이소 직접 구매 리셀링 (법무팀 확인 완료)
- [ ] 다이소 구매 조건 검토 (재판매 제한 조항)
- [ ] 상품 보증 책임 범위 (하자 배상)
- [ ] 제조사 책임보험 (제품 결함)

---

## 【2. 전자상거래법 준수】

- [ ] 특정거래 신고 (ISMS 인증)
- [ ] 환불/반품 정책 (법정 30일)
- [ ] 거짓/과장 광고 금지
- [ ] 개인정보 취급방침
- [ ] 이용약관 명시

---

## 【3. 개인정보보호법】

- [ ] 고객 데이터 처리 규정 (GDPR 준수)
- [ ] 결제 정보 보안 (PCI-DSS)
- [ ] 배송 주소 암호화
- [ ] 리마케팅 동의 절차
- [ ] 데이터 삭제 정책

---

## 【4. 광고법 검토】

- [ ] 상품 설명 허위/과장 금지
- [ ] 쿠폰/할인 표기 투명성
- [ ] 인플루언서 광고 공시
- [ ] 가격 비교 표기 정확성
- [ ] "지금만 할인" 등 기간 명시

---

## 【5. 결제/정산 법규】

- [ ] Stripe/PG사 이용약관 준수
- [ ] 취소/환불 규정 (정산 기한)
- [ ] 수수료 공시 (고객 명시)
- [ ] 통장 명의 정확성 (세무)

---

## 【6. 배송/배송사 계약】

- [ ] CJ대한통운 계약 (단체/대량 할인)
- [ ] 로젠택배 계약 조건
- [ ] 한진택배 배송 보험
- [ ] 분실/손상 배상 한도
- [ ] API 이용약관 준수

---

## 【7. 상품 이미지/저작권】

- [ ] 다이소 상품 사진 저작권 확인
- [ ] 자체 촬영 vs 다이소 제공 사진
- [ ] 경쟁사 이미지 무단 사용 금지
- [ ] 모델/인물 초상권 확인

---

## 【8. 세금/VAT 검토】

- [ ] 사업자등록 (소득세/부가세)
- [ ] 월매출 기준 VAT 신고 (8% 한국)
- [ ] 해외 배송 시 수출신고
- [ ] 환불/반품 회계 처리

---

## 【9. 소비자기본법】

- [ ] 품질 보증 기간 (6개월)
- [ ] 하자 수리/환불 절차
- [ ] 소비자 불만 대응 (48시간)
- [ ] 분쟁해결 절차 (중재/소송)

---

## 【10. Shopify/플랫폼 약관】

- [ ] Shopify 이용약관 (다중 계정 금지)
- [ ] 결제 게이트웨이 정책 (규제 상품)
- [ ] 앱 설치 약관 (데이터 접근)
- [ ] 계정 정지 조건

---

## 【11. 특수 규제 상품】

- [ ] 의약품/의료기구 (규제 확인)
- [ ] 화장품 (안전성 기준)
- [ ] 식품 (유통기한/HACCP)
- [ ] 전자기기 (전자파)
- [ ] 어린이용품 (안전인증)

---

## 【12. 분쟁/소송 대비】

- [ ] 변호사 자문 계약 (문제 시)
- [ ] 배상책임보험 가입 (제품결함)
- [ ] 분쟁 해결 절차 (고객 소송)
- [ ] 증거 보존 정책 (거래 기록)

---
