## 📊 Obsidian 그래프뷰 통계

```
총 노드 수: 40개
- 도현: 1개 (중심)
- 10명 전문가: 10개
- 도메인 영역: 5개
- 일일 스케줄: 4개
- 협력 작업: 20개

총 링크 수: 120+ 개
- 전문가 간 협력: 60개
- 도현 ↔ 전문가: 10개
- 전문가 ↔ 도메인: 50개

그래프 특징:
- 중심: 도현 (100% 연결)
- 허브: 철학/기술/비즈니스 전문가 (고도 연결)
- 커뮤니티: 5개 도메인 (각 4-5개 전문가)
```

## 📈 그래프뷰 확인 방법

**Obsidian 열기:**
1. 좌측 사이드바 → "Graph view" (그래프 아이콘)
2. 또는 Cmd+P → "Graph: Open local graph"
3. localhost:8001에서 고급 그래프 시각화 가능

**필터 및 검색:**
- 검색: "도현" → 모든 협력 관계 표시
- 검색: "비즈니스" → 비즈니스 도메인 네트워크
- 검색: "자동화" → 일일 스케줄 네트워크
