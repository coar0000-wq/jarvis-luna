# 【Daiso Direct Dropshipping 실행 계획】

✅ 법무팀 확인 (법적 문제 없음)

## 【Step 1: 초기 투자 & 재고】
```

상품 수: 5,000개
평균 구매가: $10
```

```

월 요금: $29 (Basic Plan)
결제 게이트웨이: Stripe (수수료 2.9%)
```

```
상품 설명 자동 생성 (Claude API)
가격 책정 자동화 (원가 + 20% 마진)
상품 이미지 자동 최적화
카테고리 자동 분류
```

## 【Step 4: 판매 & 배송】

주문 자동 처리
배송 자동화 (한국택배)

수익 자동 정산
