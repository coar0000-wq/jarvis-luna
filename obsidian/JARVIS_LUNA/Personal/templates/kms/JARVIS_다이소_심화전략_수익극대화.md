# 【Daiso Dropshipping 심화 전략】

## 【Phase 1: 기술 고도화 (Week 5-8)】

### **1. 동적 가격 책정 (Dynamic Pricing)**

```
방법: 실시간 경쟁사 가격 + 수요 + 재고 분석
  
Algorithm:
  └─ 기본가: 원가 × 1.4 (40% 마진)
     ├─ 경쟁사 가격 분석 (실시간)
     │  └─ 나보다 싼 경우: -5% 자동 인하
     │  └─ 나보다 비싼 경우: +10% 자동 인상
     ├─ 수요 분석 (Google Trends + SNS)
     │  └─ 인기상품: +15% 프리미엄
     │  └─ 비인기상품: -20% 판촉
     ├─ 재고 수량
     │  └─ 재고 많음: -10% (빠른 판매)
     │  └─ 재고 적음: +20% (희소성)
     └─ 계절/시간대
        └─ 저녁(8-11시): +15% (쇼핑 피크)
        └─ 오전(6-9시): -10% (저수요)

결과: 같은 상품 100개 → 100가지 가격
기대 효과: 마진율 40% → 55% (+37.5%)
```

### **2. 예측 모델 (Demand Forecasting)**

```
ML 모델: LSTM + XGBoost 앙상블

학습 데이터:
  ├─ 다이소 상품 10년 판매 기록
  ├─ 계절 트렌드 (봄/여름/가을/겨울)
  ├─ 휴일 영향도 (명절/연휴)
  ├─ SNS 트렌드 (TikTok/인스타/네이버)
  └─ 경쟁사 판매량 추정

예측:
  └─ 매일 아침 → 7일 수요 예측
     ├─ 상품별 판매량
     ├─ 필요 재고
     └─ 최적 가격

결과:
  ├─ 과잉 재고 30% 감소
  ├─ 재고 부족 50% 해결
  └─ 월 수익 +$500k
```

### **3. 이미지/설명 A/B 테스트**

```
자동 테스트 시스템:
  
각 상품마다 3가지 버전 동시 운영:
  ├─ 이미지 3가지
  │  └─ 전문 촬영 vs 심플 vs 라이프스타일
  ├─ 설명 3가지
  │  └─ 기능 중심 vs 감정 중심 vs 가격 중심
  └─ 제목 3가지
     └─ 상품명 중심 vs 검색어 최적화 vs 프로모션

실시간 성과 측정:
  ├─ 클릭율 (CTR)
  ├─ 전환율 (CVR)
  ├─ 평균 주문액 (AOV)
  └─ 수익성 (ROI)

자동 최적화:
  └─ 매주 최고 성과 버전 2배 트래픽 할당
  
기대 효과: 전환율 2% → 3.5% (+75%)
```

### **4. 성능 마케팅 (Performance Marketing)**

```
목표: 광고 ROI 최대화 (목표 300% 이상)

채널별 최적화:

📱 Facebook Ads:
  ├─ 예산: $3k/일
  ├─ 타겟: 25-45세 여성 (한국)
  ├─ LLA (쇠퇴 고객) 리타게팅
  └─ 목표 ROAS: 5:1

🎵 TikTok Ads:
  ├─ 예산: $2k/일
  ├─ 타겟: 18-35세 (생활용품 트렌드)
  ├─ 인플루언서 협업 (50만+ 팔로워 5명)
  └─ 목표 ROAS: 4:1

📺 YouTube:
  ├─ 예산: $1.5k/일
  ├─ 전환 추적 (세밀한 타게팅)
  ├─ 쇼핑 피드 연동
  └─ 목표 ROAS: 3:1

🔍 Google Search:
  ├─ 예산: $2k/일
  ├─ 고의도 키워드 (구매 직전)
  ├─ 동적 광고 (상품별 최적화)
  └─ 목표 ROAS: 6:1

📧 Email:
  ├─ 예산: $500/일 (자동화)
  ├─ 세그먼트 기반 (구매자/브라우저/이탈)
  └─ 목표 ROI: 10:1

총 예산: $9k/일 ($270k/월)
기대 수익: $9k × 5 (평균 ROAS) = $45k/일 = $1.35M/월
```

### **5. 고객 생명주기 가치 (LTV) 최적화**

```
LTV 단계별 전략:

1️⃣ Acquisition (고객 확보)
   └─ CAC: $20/명 (목표)
      ├─ Google Search (가장 효율적)
      ├─ Email 추천 (거의 무료)
      └─ 오르간 검색 (SEO)

2️⃣ Activation (첫 구매)
   └─ 전환율 목표: 3.5%
      ├─ 제한 시간 할인 (24시간)
      ├─ 무료 배송 (주문액 기준)
      └─ 신규 고객 할인 (-10%)

3️⃣ Retention (재구매)
   └─ 재구매율 목표: 35%
      ├─ 구독 박스 ($30/월, 15% 할인)
      ├─ 포인트 시스템 (구매액 5% 적립)
      ├─ 자동 재주문 (매월 인기 상품)
      └─ VIP 프로그램 (월 $100 이상)

4️⃣ Revenue (수익 증가)
   └─ AOV (평균주문액) 목표: $50 → $80
      ├─ 크로스셀 (관련 상품)
      ├─ 업셀 (프리미엄 버전)
      ├─ 번들 할인 (3개 구매 시 -15%)
      └─ 한정판 (수량 제한으로 긴급성)

5️⃣ Advocacy (추천)
   └─ 추천 프로그램
      ├─ 친구 추천 시 양쪽 $10 할인
      └─ 리뷰 작성 시 포인트 500점 (₩5k)

예상 LTV:
  └─ 고객당 월 구매: 3번
     ├─ 첫 구매: $50
     ├─ 2-12개월: $60 × 11 = $660
     ├─ 재구매율 35% 추가
     └─ 연간 LTV: $300-400
        
CAC $20 / LTV $350 = 17.5배 (매우 건강함)
```
