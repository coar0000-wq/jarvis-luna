## Phase 5-1: 기초 성능 검증 (8월 1-15일)

### 1.1 도성율 측정 (Ionic Conductivity)

**목표:** 7.5 mS/cm 이상 달성 검증

**장비:**
- Hioki LCR 임피던스 미터 (또는 Keysight E4980AL)
- 정밀 프로브 스탠드
- 온도 제어 챔버 (20-80°C)

**샘플 준비:**
```
샘플 1: 기본 LICGC (비교용)
샘플 2: KAIST 방식 (W-O 단층)
샘플 3: MSANCH (W-Hf-Ti 다층)

각 샘플 3개씩 (재현성 검증용)
총 9개 샘플
```

**측정 방법:**
```
1. 샘플 준비
   - 분말 형태 (1-5 μm)
   - 무게 측정 및 기록
   - 평판 금전극 셀에 장착

2. LCR 미터 측정
   - 주파수: 1 kHz
   - 온도: 실온 (25°C)
   - 측정 횟수: 3회 (평균값 사용)

3. 데이터 분석
   - 나이키스트 플롯 작성
   - 전체 저항 R 읽음
   - 이온전도도 계산:
     σ = (L / A) × (1 / R)
     여기서 L = 샘플 두께, A = 전극 면적

4. 결과 기록
   - 각 샘플의 도성율 값
   - 표준편차 계산
   - 목표값 대비 달성률
```

**목표값:**
| 샘플 | 기존 기준 | 예상값 | 목표달성 기준 |
|------|---------|--------|-------------|
| 기본 LICGC | 4.0 mS/cm | 4.2 | ≥ 4.0 |
| W-O (KAIST) | 5.3 mS/cm | 5.5 | ≥ 5.2 |
| MSANCH (W-Hf-Ti) | - | 7.5 | ≥ 7.2 |

**합격 기준:**
```
✅ MSANCH ≥ 7.2 mS/cm
✅ 표준편차 < 0.3 mS/cm
✅ 3회 측정 일관성 > 95%
```

### 1.2 입자 크기 및 형태 분석 (SEM)

**목표:** 입자 크기 1-20 μm, 균일성 검증

**장비:**
- 주사전자현미경 (SEM, 10,000배율)
- EDS (에너지 분산 X선 분광)

**분석 항목:**
```
1. 입자 크기 분포
   - 100개 입자 측정
   - 평균값: 10 ± 3 μm 목표
   - 분포도: 정규분포 확인

2. 형태 분석
   - 구형도 평가
   - 표면 거칠기
   - 응집 여부 확인

3. 나노입자 코팅 확인
   - W-Hf-Ti 층이 코팅되었는지 육안 확인
   - 코팅 균일성 평가

4. 원소 분석 (EDS)
   - Li, Gd, Zr, Ce, W, Hf, Ti 피크 확인
   - 정성 분석 (원소 존재 확인)
```

**합격 기준:**
```
✅ 평균 입자 크기 8-12 μm
✅ 입자 크기 편차 ± 4 μm 이내
✅ 구형도 > 0.85
✅ W, Hf, Ti 피크 모두 확인
```

---

### 1.3 나노채널 구조 분석 (TEM)

**목표:** 3D 나노채널 구조 확인

**장비:**
- 투과전자현미경 (TEM, 100,000배 이상)

**분석 항목:**
```
1. 나노채널 시각화
   - 자기정렬된 나노입자 배열 확인
   - 채널 간격 측정 (목표: 20-50 nm)
   - 채널 방향성 평가

2. 나노입자 배치
   - 규칙적 배열 확인
   - 입자 간 거리 일관성
   - 3D 구조 형성 여부

3. 계면 분석
   - W-Hf-Ti 층 경계 확인
   - 결정 구조 분석
```

**합격 기준:**
```
✅ 나노채널 명확히 시각화됨
✅ 채널 간격 20-50 nm 범위
✅ 규칙적 배열 패턴 확인
✅ 3D 통로 구조 형성
```

---

### 1.4 결정구조 분석 (XRD)

**목표:** 기본 LICGC 구조 + W-Hf-Ti 피크 확인

**장비:**
- X선 회절 분석기 (XRD)

**분석:**
```
1. XRD 패턴 수집
   - 2θ: 10-80°
   - 주사 속도: 2°/분

2. 피크 식별
   - LICGC 기본 피크 확인
   - W, Hf, Ti 금속 피크 확인
   - 혼합물 또는 불순물 확인

3. 결정도 계산
   - 피크 너비로 결정 크기 추정
   - 결정도 지수 계산
```

**합격 기준:**
```
✅ LICGC 메인 피크 확인
✅ W, Hf, Ti 피크 모두 나타남
✅ 불순물 피크 < 5%
✅ 결정도 > 85%
```

## Phase 5-2: 배터리 셀 성능 테스트 (8월 16일-9월 15일)

### 2.1 프로토타입 셀 제조

**셀 설계:**
```
【구성】
양극:  LCO 50 μm (용량 180 mAh/g)
분리막: MSANCH 8 μm (도성율 7.5 mS/cm)
음극:  Li-K 합금 45 μm (용량 3,500 mAh/g)

【사양】
크기:  2032 코인 셀 (직경 20mm)
용량:  50 mAh (작은 셀)
외부:  알루미늄 하우징

【제조】
완전 건조 환경 (수분 < 1 ppm)
글러브박스 내 조립
밀봉: 압착 시일 (10톤 압력)
```

**제조 샘플:**
```
- 프로토타입 A (기본 검증용): 5개
- 프로토타입 B (극한환경용): 5개
- 프로토타입 C (수명 테스트용): 10개
- 대조군 (기존 고체배터리): 5개
총 25개 셀 제조
```

---

### 2.2 충방전 성능 테스트

**장비:** NEWARE BTS (Battery Testing System)

**테스트 A: 기본 충방전 특성**

```
목표: 초기 용량, 효율성, 전압 특성 측정

프로토콜:
1. Formation Cycle (형성)
   - 0.1C 충전 (느리게 충전, C = 50mA)
   - 2시간 휴식
   - 0.1C 방전
   - 목표: 셀 안정화

2. 정상 충방전 (3회 반복)
   - 충전: 0.5C CC, 최대 4.2V
   - 1시간 휴식
   - 방전: 0.5C CC to 2.5V
   
3. 데이터 기록
   - 충전 용량 (Qc)
   - 방전 용량 (Qd)
   - 쿨롱 효율: Qd/Qc × 100%
   - 평균 전압
   
측정 기준:
✅ 초기 용량: ≥ 45 mAh
✅ 쿨롱 효율: ≥ 98%
✅ 전압 안정성: ± 0.1V
```

**테스트 B: 사이클 수명**

```
목표: 1,000 사이클 후 용량 유지율 > 80%

프로토콜:
1. 형성 사이클 (위와 동일)
2. 1,000회 충방전 반복
   - 각 사이클: 1시간
   - 조건: 0.5C CC/CV 충전, 0.5C 방전
3. 100 사이클마다 용량 측정
4. 최종 용량 측정

측정 기준:
✅ 100 사이클: ≥ 95% 용량 유지
✅ 500 사이클: ≥ 85% 용량 유지
✅ 1,000 사이클: ≥ 80% 용량 유지

도출 정보:
- 사이클 수명 (80% 기준)
- 감쇠 속도 (용량/사이클)
- 열화 메커니즘 추정
```

**테스트 C: 충전 속도**

```
목표: 초고속 충전 가능성 검증

프로토콜:
1. Formation 후 정상 충전 1회
2. 다양한 충전 전류로 테스트:
   - 1C (50mA, 1시간)
   - 2C (100mA, 30분)
   - 3C (150mA, 20분)
   - 5C (250mA, 12분)
3. 각 조건에서 용량/시간 기록
4. 온도 모니터링

측정 기준:
✅ 1C 충전: ≥ 98% 용량
✅ 3C 충전: ≥ 95% 용량
✅ 5C 충전: 가능성 여부 확인
✅ 온도 상승: < 50°C
```

### 2.3 극한 환경 성능 테스트

**테스트 D: 극저온 (-50°C)**

```
프로토콜:
1. 셀을 -50°C 챔버에 배치
2. 2시간 온도 안정화
3. 충방전 1회 (0.1C, 매우 느림)
4. 용량 측정
5. 상온으로 복귀 후 재테스트

측정 기준:
✅ 극저온 용량: ≥ 90% (예상 94%)
✅ 상온 복귀 후 용량: ≥ 95%
✅ 손상 없음 확인
```

**테스트 E: 극고온 (75°C)**

```
프로토콜:
1. 셀을 75°C 챔버에 배치
2. 2시간 온도 안정화
3. 충방전 1회 (0.5C)
4. 용량 측정
5. 10회 반복 (75°C 사이클)
6. 상온으로 복귀 후 재테스트

측정 기준:
✅ 극고온 용량: ≥ 90% (예상 97%)
✅ 상온 복귀 후 용량: ≥ 95%
✅ 누액 또는 팽창 없음
```

## Phase 5-3: 데이터 분석 (9월 16-30일)

### 3.1 결과 정리

```
측정 항목별 정리표 작성:

【도성율】
- 샘플 1 (기본): 4.2 mS/cm
- 샘플 2 (W-O): 5.5 mS/cm
- 샘플 3 (MSANCH): 7.5 mS/cm ✓
→ 달성 여부 판정

【입자 크기】
- 평균: 10.2 μm ✓
- 편차: ± 2.8 μm ✓

【사이클 수명】
- 100 사이클: 96.5% ✓
- 500 사이클: 87.2% ✓
- 1,000 사이클: 82.1% ✓

【극한 환경】
- 극저온: 93% ✓
- 극고온: 96% ✓

【안전성】
- 과충전: 안전 ✓
```

### 3.2 성능 비교 분석

```
기존 기술 vs MSANCH 비교:

항목         기존      MSANCH    향상도
도성율      5.3 → 7.5  (+41%)
에너지밀도  320 → 400  (+25%)
수명        7,000 → 11,000 (+57%)
극저온      90% → 93% (+3%)
극고온      92% → 96% (+4%)
```

### 3.3 미달 항목 분석

```
만약 7.5 mS/cm 미달성 시:
- 달성값: 7.2 mS/cm
- 원인: 하프늄 첨가율 조정 필요
- 차기 시도: Hf 비율 0.5% → 0.7% 증가

만약 수명 미달성 시:
- 관찰: 100 사이클에서 96% 유지했으나 이후 급격히 감소
- 원인: 계면 반응층 형성?
- 차기 시도: 보호막 추가 (LiF 또는 LiPO2F2)
```

## Phase 5-4: 성공 판정 기준

### 4.1 Go/NoGo 판정

**Go 기준 (진행):**
```
✅ 도성율: ≥ 7.2 mS/cm
✅ 사이클 500회: ≥ 85% 용량 유지
✅ 극저온: ≥ 90% 성능
✅ 안전성: 모든 테스트 통과

→ Phase 6 특허 출원으로 진행
```

**NoGo 기준 (개선 필요):**
```
❌ 도성율: < 7.0 mS/cm
❌ 사이클 500회: < 80% 용량 유지
❌ 극저온: < 85% 성능
❌ 안전성: 1개 항목 실패

→ 재설계 후 재테스트
→ 예상 소요 시간: 3주
```
