```

  ├─ Amazon (아마존 한국 상품 카테고리)

  ├─ Shopify (경쟁 스토어 20개)
  ├─ Walmart (온라인)
  └─ Target (온라인)

일본 (물리상품):
  ├─ 야후 쇼핑
  ├─ 라쿠텐
  ├─ Amazon 일본
  ├─ Etsy 일본
  └─ Shopify 일본

기술:
  ├─ Beautiful Soup (웹 크롤링)
  ├─ Selenium (JavaScript 렌더링)
  ├─ Scrapy (대규모 크롤링)
  └─ 프록시 로테이션 (차단 회피)

데이터 저장:
  ├─ PostgreSQL (실시간 가격)
  ├─ Redis (캐시, 빠른 조회)
  └─ S3 (히스토리 아카이브)

자동 분석:
  ├─ 평균 가격 계산
  ├─ 가격 범위 (최저-최고)
  ├─ 가격 변동 추세
  ├─ 마진율 자동 계산
  └─ 동적 가격 제안

예시 데이터셋 (완성 목표):
  ```

    ├─ 원가: $1

### **3. 상품 카테고리 완전 분석**

```

  └─ 추천 판매 카테고리 Top 100 도출

방법:

Step 1: 다이소 카테고리 매핑
  ├─ 생활용품 (청소/세제)
  ├─ 주방용품 (조리도구/보관)
  ├─ 미용/뷰티 (스킨케어/메이크업)
  ├─ 사무/스태셔너리 (노트/펜/클립)
  ├─ 홈 데코 (조명/식물/그림)
  ├─ 의류/액세서리 (양말/모자/가방)
  ├─ 전자제품 (USB/충전기/케이블)
  ├─ 건강/운동 (요가매트/손난로/가습기)
  ├─ 스포츠/장난감 (공/보드게임/인형)
  └─ 기타 (선물/계절용품)

Step 2: 미국 수요 분석
  
  각 카테고리별로:
  ├─ 검색량 (Google Trends)
  ├─ 경쟁 상품 수 (Amazon/Etsy)
  ├─ 평균 판매가
  ├─ 평균 마진율
  ├─ 배송 용이성 (무게/부피)
  └─ 경쟁 강도 (낮음/중간/높음)

  평가: 인기지만 경쟁 높음
  JARVIS 전략: 니치 상품에 집중 (소수 상품만)
  예: 페이스팩 시트, 립티트, 쿠션 파운데이션
  
  추천 상품: 10개
  월 판매 목표: $500k
  ```

Step 3: 일본 수요 분석

### **4. 고객 수요 패턴 학습**

```
🎯 목표:
  ├─ 구매 패턴 분석 (계절/시간대/요일)
  ├─ 고객층 세분화 (나이/성별/지역)
  ├─ 가격대별 수요 곡선
  ├─ 재구매 패턴 (반복 구매율)
  └─ AI 모델로 미래 수요 예측

  ├─ 월별 리뷰 수 (계절 패턴)

  ├─ 시간대별 판매 분포
  ├─ 요일별 판매 분포
  ├─ 가격대별 판매량

  ```
  상품: K-뷰티 페이스팩
  
  계절 패턴:
  ├─ 봄 (3-5월): 기본 수요

  ├─ 저녁 (18-23시): +80% (퇴근 후 쇼핑 피크)
  ├─ 밤 (23-6시): -30% (낮은 수요)

  ├─ 가격: $12-18 범위에서 동적 책정

### **5. 배송비 & 관세 정보**

```
🎯 목표:
  ├─ 한국 → 미국 배송비 완전 파악
  ├─ 한국 → 일본 배송비 완전 파악
  ├─ 미국 관세 (duties/tariffs) 계산
  ├─ 일본 소비세 (consumption tax) 계산
  └─ 배송 방법별 최적 선택 알고리즘

데이터 수집:

한국 → 미국 배송:
  
  배송사별 요금 (kg 기준):
  ├─ DHL Express: $15-25/kg (빠름, 비쌈)
  ├─ FedEx International: $12-18/kg (중간)
  ├─ UPS International: $10-16/kg (경제)
  ├─ USPS International: $8-12/kg (느림, 쌈)
  └─ 한국우정 EMS: $9-14/kg (중간)

선택 기준 (JARVIS):
  ├─ 무게 < 0.5kg: 소량 배송 (예: 화장품)
  ├─ 무게 0.5-2kg: 일반 배송 (예: 스태셔너리)
  ├─ 무게 > 2kg: 해운 (느림, 저가)
  └─ 배송 기간 & 비용 균형

관세 (Tariffs):
  
  카테고리별 관세율:
  ├─ 화장품/뷰티: 0-5% (낮음)
  ├─ 일반 생활용품: 10-15% (중간)
  ├─ 의류: 15-25% (높음)
  ├─ 전자제품: 5-10% (중간)
  └─ 간식/음식: 10-20% (높음, 특별 검사 가능)

배송비 완전 계산 (예시):
  ```
  상품: K-뷰티 페이스팩 10개 (무게 0.3kg)
  
  비용 분석:
  ├─ 다이소 원가: $10 (1개당 $1)
  ├─ 배송비: $3 (FedEx, 한국→미국)
  ├─ 관세: $1 (10% 가정, 화장품)
  ├─ 포장/라벨: $0.5
  ├─ Shopify 수수료: 2.9% + $0.30
  └─ 최종 원가: $14.90
