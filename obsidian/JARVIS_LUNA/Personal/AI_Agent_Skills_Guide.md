## 🤖 AI 에이전트 스킬 개요

**정의**: 에이전트가 작업을 자동으로 수행하기 위한 모듈식 능력 패키지

**특징**:
- 🔄 워크플로우 자동화
- 🧠 다중 에이전트 아키텍처
- 💾 메모리 및 컨텍스트 관리
- ⚡ 실시간 에러 추적
- 🔗 외부 서비스 통합

## 🔴 TIER 1: 에이전트 필수 스킬

### 1. **mcp-builder** ⭐⭐⭐ (필수)

| 항목 | 설명 |
|------|------|
| **용도** | MCP 서버 구축 |
| **대상** | Obsidian 커스텀 에이전트 |
| **기능** | 외부 도구 연결, API 통합 |
| **중요도** | ⭐⭐⭐ 필수 |

**MCP란:**
- Model Context Protocol
- 에이전트가 외부 도구 접근
- 표준화된 인터페이스
- 새로운 능력 추가 가능

---

### 2. **multi-agent-architecture** ⭐⭐⭐ (필수)

| 항목 | 설명 |
|------|------|
| **용도** | 다중 에이전트 시스템 설계 |
| **특징** | 역할 분담, 메시지 전달 |
| **사용** | 복잡한 작업 분해 |
| **중요도** | ⭐⭐⭐ 필수 |

**구성요소:**
1. Orchestrator Agent - 조율
2. Task Agents - 작업 수행
3. Reviewer Agent - 검증
4. Memory Agent - 기억 관리

---

### 3. **memory-systems** ⭐⭐⭐ (필수)

| 항목 | 설명 |
|------|------|
| **용도** | 에이전트 메모리 시스템 |
| **메모리 타입** | 단기, 장기, 의미적 |
| **기능** | 학습, 재사용, 최적화 |
| **중요도** | ⭐⭐⭐ 필수 |

**메모리 종류:**
- **단기**: 현재 작업 컨텍스트
- **장기**: 완료된 작업 기록
- **의미적**: 학습된 패턴

---

### 4. **context-optimization** ⭐⭐⭐ (필수)

| 항목 | 설명 |
|------|------|
| **용도** | 컨텍스트 윈도우 최적화 |
| **기능** | 토큰 절약, 효율성 증대 |
| **절약율** | 30-50% 토큰 감소 |
| **중요도** | ⭐⭐⭐ 필수 |

**최적화 기법:**
1. 요약 (Summarization)
2. 캐싱 (Caching)
3. 우선순위 지정 (Prioritization)
4. 청킹 (Chunking)

## 🎯 에이전트 설계 원칙

### 1. 역할 분리 (Role Separation)
각 에이전트는 명확한 책임을 가짐

### 2. 메시지 기반 통신 (Message-Based Communication)
에이전트 간 비동기 메시지 전달

### 3. 메모리 관리 (Memory Management)
학습 내용 자동 저장 및 재사용

### 4. 컨텍스트 최적화 (Context Optimization)
토큰 효율성 극대화

### 5. 에러 처리 (Error Handling)
자동 재시도 및 폴백 메커니즘

### 6. 모니터링 (Monitoring)
실시간 성능 추적

## 💡 에이전트 베스트 프랙티스

### ✅ DO:
- 에이전트 책임 명확히 하기
- 메모리 시스템 구축하기
- 실시간 모니터링하기
- 정기적으로 테스트하기
- 에러 로깅하기

### ❌ DON'T:
- 하나의 에이전트에 여러 책임
- 메모리 시스템 없이 장기 실행
- 모니터링 없는 배포
- 테스트 없는 업데이트
- 에러 무시하기
