# 【Daiso Dropshipping 스킬 데이터 수집】

## 【Step 4: 상품 설명 자동화】

### 필요 스킬
```
1. 제품 카테고리 분류 (100개)
2. SEO 최적화 키워드 (상품별)
3. 설명 템플릿 (10가지)
4. 이미지 최적화 (해상도/크기)
5. 리뷰 자동 수집 및 요약
```

### 데이터 수집
```
- 다이소 기존 상품 설명 분석 (1,000개)
- 경쟁사 상품 설명 (Amazon/eBay 500개)
- SEO 키워드 도구 (Ahrefs/SEMrush)
- 이미지 압축 라이브러리
```

---

## 【Step 5: 판매/배송 자동화】

### 필요 스킬
```
1. 주문 처리 API (Shopify)
2. 배송사 연동 (CJ/로젠/한진)
3. 재고 관리 시스템
4. 환불 자동 처리
5. 배송 추적 시스템
```

### 데이터 수집
```
- Shopify Fulfillment API 문서
- 택배사 실시간 API (3개사)
- 배송비 계산 로직 (무게/거리)
- 환불 정책 자동화 규칙
```

---

## 【Step 6: 수익 정산 자동화】

### 필요 스킬
```
1. 실시간 매출 대시보드
2. 원가 계산 (자동)
3. 마진율 최적화 (ML)
4. 정산 자동화 (은행/PG)
5. 세무 보고 (자동)
```

### 데이터 수집
```
- 다이소 원가 데이터 (5,000개 상품)
- 시장 가격 데이터 (경쟁사 5개)
- 마진율 벤치마크 (업계 평균)
- 정산 규정 (PG사/은행)
```
