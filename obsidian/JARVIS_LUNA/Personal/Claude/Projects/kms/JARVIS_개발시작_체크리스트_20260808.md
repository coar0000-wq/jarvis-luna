## ✅ **Step별 체크리스트**

### **Phase 1: Supabase 설정 (5분)**

```
[ ] 1️⃣ Supabase.com 접속
[ ] 2️⃣ New Project 생성
    - Name: satellite-ai-dev
    - Password: [강력한 것]
    - Region: Tokyo (ap-northeast-1)
[ ] 3️⃣ 프로젝트 생성 완료 대기 (3분)
[ ] 4️⃣ Settings → API 에서 복사
    - Project URL
    - Anon Key
    - Service Role Key

✅ 완료 후: 다음 단계 진행
❌ 막혔을 때: JARVIS에 알려줘
```

### **Phase 2: Database 스키마 (5분)**

```
[ ] 1️⃣ Supabase SQL Editor 열기
[ ] 2️⃣ schema.sql 전체 복사
    경로: satellite-ai-saas/database/schema.sql
[ ] 3️⃣ SQL Editor에 붙여넣고 Run
[ ] 4️⃣ Storage → New Bucket
    - Name: images
    - Privacy: Public

✅ 완료 후: 다음 단계 진행
```

### **Phase 3: Frontend 시작 (10분)**

```
[ ] 1️⃣ Terminal 열기
[ ] 2️⃣ cd satellite-ai-saas/frontend
[ ] 3️⃣ cp ../.env.local.example .env.local
[ ] 4️⃣ .env.local 수정
    NEXT_PUBLIC_SUPABASE_URL=[Supabase URL]
    NEXT_PUBLIC_SUPABASE_ANON_KEY=[Anon Key]
[ ] 5️⃣ npm install
[ ] 6️⃣ npm run dev
[ ] 7️⃣ http://localhost:3000 접속 확인

✅ 완료 후: 다음 단계 진행
```

### **Phase 4: Backend 시작 (10분)**

```
[ ] 1️⃣ 새 Terminal 열기
[ ] 2️⃣ cd satellite-ai-saas/backend
[ ] 3️⃣ python -m venv venv
[ ] 4️⃣ source venv/bin/activate (Mac/Linux)
        또는 venv\Scripts\activate (Windows)
[ ] 5️⃣ pip install -r requirements.txt
[ ] 6️⃣ python main.py
[ ] 7️⃣ http://localhost:8000/health 확인

✅ 완료 후: 통합 테스트!
```

### **Phase 5: 통합 테스트 (5분)**

```
[ ] 1️⃣ Frontend: http://localhost:3000 열기
[ ] 2️⃣ Backend: http://localhost:8000/docs 열기
[ ] 3️⃣ 홈페이지 로드 확인
[ ] 4️⃣ 구조 확인

✅ 모든 것이 작동하면 완료!
```

## ⚠️ **문제 해결**

```
npm install 에러?
→ Node.js 버전 확인 (18+ 필요)

pip install 에러?
→ Python 버전 확인 (3.9+ 필요)

Supabase 연결 실패?
→ API 키 재확인
→ SUPABASE_URL 확인

포트 충돌?
→ npm run dev -- -p 3001
→ python main.py --port 8001
```
