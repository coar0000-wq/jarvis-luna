```
├─ 치료 (약물 → 질병, 효율도 0-1)
├─ 상호작용 (약물 ↔ 약물, 강도)
├─ 활성화/억제 (유전자 → 단백질)
├─ 유발 (증상 ← 질병)
└─ 진단 (검사 → 질병, 정확도)
```

**자동 온톨로지 구축:**
- 엔티티 추출: NER (의료 용어 5,000개)
- 관계 추출: RE 모델 (관계 타입 50+)
- 메타데이터: 신뢰도, 출처, 시간가중치

#### 🧠 2️⃣ 추론 엔진 (Reasoning Engine) - **핵심**

```
입력: 환자 정보
  "35세 여성, 두통 + 피로 3주, 철 수치 낮음"
  
↓ 추론 엔진 (Logic + Graph)

Step 1: 규칙 기반 추론
  IF 두통 + 피로 + 철수치↓ THEN 빈혈 의심 (신뢰도 0.85)
  IF 빈혈 의심 + 여성 + 35세 THEN 생리과다 검토 (신뢰도 0.72)

Step 2: 그래프 경로 추론
  증상(두통) --유발--> 질병(빈혈)
  질병(빈혈) --치료--> 약물(철분제)
  약물(철분제) --부작용--> 증상(위장장애)

Step 3: 확률 기반 추론
  P(빈혈|두통, 피로, 철저하) = 0.88
  P(생리과다|빈혈, 여성, 나이) = 0.72
  P(다른질병|증상) = 0.05

Step 4: 최적 진단 결정
  진단: 빈혈 (신뢰도 88%)
  추가검사: 생식기 초음파, 위내시경
  치료: 철분제 + 비타민 B12
  
출력: 진단 경로 + 확률 + 설명
```

**기술 스택:**
- 규칙 엔진: Prolog / CLIPS
- 확률 추론: Bayesian Networks (PyMC)
- 경로 추론: Graph Pattern Matching (Neo4j Cypher)
- 제약 만족: CSP (python-constraint)
- 통합: Neuro-Symbolic 통합

**특징:**
- 투명성: 모든 추론 과정 시각화
- 신뢰성: 확률 계산으로 신뢰도 표시
- 확장성: 새 규칙 자동 추가
- 설명가능성: "왜 이 진단인가?" 답변

#### 📊 3️⃣ GNN 모델 (고차 추론)

```
Graph Neural Networks로 숨겨진 패턴 발견

입력: 그래프 (노드 + 엣지)
  
↓ GraphSAGE / GAT / GCN

1. 노드 임베딩 학습
   - 각 질병/약물을 벡터로 변환
   - 이웃 노드 정보 집계
   
2. 관계 예측
   - 아직 발견되지 않은 약물-질병 관계 예측
   - 약물-약물 상호작용 예측
   - 신약-기존약 조합 효과 예측

3. 이상 탐지
   - 비정상 약물 반응 패턴 발견
   - 드문 질병 조합 탐지
   - 신약 부작용 조기 경고
```

**모델 사양:**

- 검증 정확도: 94%+

#### ⚛️ 4️⃣ 인과관계 분석 (Causal Inference)

```
단순 상관: A와 B가 함께 증가
인과: A → B (A가 B의 원인)

정책 시뮬레이션:
  "약가 25% 인하 → 환자 방문 몇% 증가?"

1. 인과그래프 구축
   약가 ← 정책
   약가 → 환자접근성
   환자접근성 → 환자방문
   
2. 인과효과 추정 (Causal Forests)
   개별 치료효과 (HTE)
   이질적 반응 탐지
   
3. 정책 시뮬레이션
   약가 인하 25% ⇒ 환자방문 +35% (신뢰도 92%)
   
4. 의사결정
   ROI 계산 → 정책 결정
```

**라이브러리:**
- DoWhy: 인과효과 추정
- EconML: 이질적 효과
- CausalML: 정책 평가
- Causal Forest: 고급 추론
