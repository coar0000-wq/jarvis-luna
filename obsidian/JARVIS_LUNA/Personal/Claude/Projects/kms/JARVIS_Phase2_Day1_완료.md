## 💡 **기술 스택**

### 신경심볼릭 AI
```
신경망 (Phase 1):
  ├─ 입력: 도메인별 특성
  ├─ 출력: 예측 + 신뢰도
  └─ 성능: 95.2% 정확도

논리 엔진 (신규):
  ├─ 규칙: 6개 도메인 × N개 규칙
  ├─ 조건 매칭: 도메인 기반
  └─ 신뢰도 결합: 조화 평균

설명가능성 모듈:
  ├─ 템플릿: 5개 (도메인별)
  ├─ 설명: 단순/상세 (2단계)
  └─ 점수: 규칙 깊이 기반
```

### 양자 알고리즘 기초
```
양자 회로:
  ├─ 게이트: Hadamard, Pauli-XYZ, CNOT
  ├─ 큐빗: 4-6개 (확장성)
  └─ 측정: 상태 확률 계산

VQE (분자 에너지):
  ├─ Ansatz: 매개변수화 회로
  ├─ 목적함수: 에너지 최소화
  └─ 최적화: 그래디언트 기반

QAOA (조합 최적화):
  ├─ Cost Hamiltonian: Pauli-Z
  ├─ Mixer Hamiltonian: Pauli-X
  └─ 목적함수: MAX-CUT 문제
```
