### **Day 2-3 (8월 11-12일) - 나노구조화 (Sample 1-1, 1-2)**

#### **Sample 1-1: 나노구조 LiBH4 (대조군)**

**절차:**

```
Step 1: LiBH4 준비
- LiBH4 2.0g 측정 (정밀 저울, ±0.1mg)
- PTFE 내용기에 입력
- 스틸볼 (12mm × 50g) 3개 추가
- 뚜껑 닫기

Step 2: 볼밀링
- 시간: 24시간 연속
- 속도: 200 RPM
- 환경: 아르곤 충전
- 온도: 실온 (20-25°C)
- 음향 모니터링: 규칙적 진동음 확인

Step 3: 냉각 및 건조
- 진공 건조: 80°C, 4시간
- 냉각: 실온 도달 (약 30분)
- 저장: 아르곤 밀봉 용기
```

**데이터 기록:**

```
Sample 1-1 (나노구조 LiBH4)
────────────────────────────
초기 질량: 2.0000 g
최종 질량: 1.9950 g (손실 0.025%, 허용 범위)
색상 변화: 흰색 → 회백색 (나노화 확인)
입자 크기 예상: 50-200 nm (SEM 측정 보류)
```

#### **Sample 1-2: Mg 도핑 LiBH4**

**절차:**

```
Step 1: Mg(NO₃)₂ 용해
- Mg(NO₃)₂ 20mg 측정
- 무수 에탄올 5mL에 용해 (초음파 5분)
- 결과: 투명 용액

Step 2: 혼합
- 나노구조 LiBH4 2g과 혼합
- 실온에서 6시간 교반 (자석 교반기)
- 모니터링: 고르지 않은 분산 → 균일 분산

Step 3: 건조 및 열처리
- 진공 건조: 60°C, 2시간
- 냉각: 실온
- 열처리: 300°C, 질소 분위기, 2시간
- 냉각: 실온

Step 4: 저장
- 아르곤 글러브박스 내 보관
```

**데이터 기록:**

```
Sample 1-2 (Mg 도핑, 1%)
────────────────────────────
초기 질량: 2.0000 g (LiBH4)
Mg(NO₃)₂: 0.0200 g (1 mol% 계산)
최종 질량: 1.9960 g (열처리 후)
색상 변화: 회백색 → 연갈색 (산화 가능성 최소)
Mg 함량 예상: 1.0 mol% (EDS 검증 보류)
```

**예상 결과:**
✅ 2개 샘플 완성
✅ 나노구조 확인 (색상 변화)
✅ 도핑 성공 (질량 변화 미세)

### **Day 4-5 (8월 13-14일) - 다층 도핑 (Sample 1-3, 1-4)**

```
- 냉각: 실온
```

### **Day 6-7 (8월 15-16일) - 표면 개질 (Sample 1-4 코팅, Sample 1-5)**

#### **표면 코팅: Al2O3 + LiF**

**절차:**

```
Step 1: Al2O3 코팅
- Sample 1-4 (완전 HNSD) 2g + Al(OiPr)₃ 100mg 혼합
- 실온에서 30분 교반
- 진공 건조: 100°C, 2시간
- 열처리: 250°C, 질소, 2시간
→ Al2O3 코팅층 형성 (5-10 nm 예상)

Step 2: LiF 이중 코팅
- LiF 분말 2g과 1:1 비율 혼합
- 에탄올 8mL에 분산
- 초음파 처리: 15분
- 진공 건조: 30°C, 2시간
- 저온 열처리: 120°C, 질소, 2시간
→ LiF 코팅층 형성 (10-15 nm 예상)
```

**데이터 기록:**

```
Sample 1-4 (표면 코팅 완료)
───────────────────────────
Al2O3 코팅 전: 1.9980 g
Al2O3 코팅 후: 2.0020 g (+0.2%)
LiF 코팅 후: 2.0100 g (+0.4%)
색상: 회황색 → 연회색 (표면 부드러워짐)
외관: 나노입자 표면 매끈함 (우수)
```

#### **Sample 1-5: 최적화 HNSD (고도핑)**

**절차:** 1-4와 동일하지만 도핑량 증가


**데이터 기록:**

```
Sample 1-5 (최적화 버전)
─────────────────────────

색상: 회황색 → 진회색 (도핑 강화)
외관: 나노입자 표면 코팅 우수
특징: Sample 1-4보다 짙은 색상 (도핑량 증가 확인)
```

**예상 결과:**
