## 💡 **기술 스택**

### 양자 신약 설계 파이프라인

```
1️⃣ 분자 입력
   └─ 원자 조성, 결합 길이

2️⃣ VQE 최적화 (양자)
   ├─ Ansatz 회로 생성
   ├─ 분자 에너지 계산
   ├─ 그래디언트 기반 최적화 (50회 반복)
   └─ 수렴 판정

3️⃣ 신약 평가
   ├─ 정확도 계산
   ├─ 신약점수 산정
   ├─ 개발 시간 예측
   └─ 잠재력 분류

4️⃣ 결과 보고
   └─ JSON 형식 저장
```

### VQE 알고리즘 상세

```
입력: 분자 (원자 조성)
↓
Ansatz 회로 생성
  ├─ Hadamard 층 (중첩)
  ├─ 회전 층 (매개변수화)
  └─ CNOT 게이트 (얽힘)
↓
에너지 계산 (목적함수)
  └─ ||Ψ(θ)⟩의 Hamiltonian 기댓값
↓
그래디언트 계산
  └─ 수치 미분 (finite difference)
↓
매개변수 업데이트
  └─ θ ← θ - η∇E(θ)
↓
반복 (50회)
  └─ 수렴 판정
↓
최적 에너지 및 상태 반환
```
