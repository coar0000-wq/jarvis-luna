## MCP vs API 비교

### [[MCP vs Traditional API]]

#### 차이점

[[Key Differences]]:

**MCP**:
- [[Standardized Protocol]]: 표준 프로토콜
- [[AI Optimized]]: AI 최적화
- [[Bidirectional]]: 양방향 통신
- [[Resource Management]]: 리소스 관리
- [[Context Aware]]: 맥락 인식

**Traditional API**:
- [[Custom Protocol]]: 커스텀 프로토콜
- [[General Purpose]]: 범용
- [[Unidirectional]]: 단방향
- [[No State Management]]: 상태 관리 없음
- [[Stateless]]: 무상태

#### 선택 기준

[[Decision Criteria]]:
- [[Use MCP]]: AI와의 통합이 필요할 때
- [[Use API]]: 일반적인 REST API가 필요할 때
- [[Combine]]: 둘 다 필요할 때
- [[Context]]: 맥락 유지가 필요할 때
- [[Scale]]: 확장성이 중요할 때
