## RAG (Retrieval-Augmented Generation)

### [[RAG Architecture]]

**RAG의 개념**:
[[Retrieval-Augmented Generation]]:
- [[Definition]]: 검색 증강 생성
- [[Hybrid Approach]]: 하이브리드 방식
- [[Combines Both]]: 검색 + 생성
- [[Accuracy Enhanced]]: 정확도 향상
- [[Context Aware]]: 맥락 인식

[[RAG Components]]:

**Retrieval Module** (검색 모듈):
- [[Document Search]]: 문서 검색
- [[Query Matching]]: 쿼리 매칭
- [[Ranking]]: 순위 매김
- [[Relevance Scoring]]: 관련도 점수

**Generation Module** (생성 모듈):
- [[Context Synthesis]]: 맥락 합성
- [[Answer Generation]]: 답변 생성
- [[Language Model]]: 언어 모델
- [[Response Quality]]: 응답 품질

#### RAG의 장점

[[RAG Benefits]]:
- [[Up-to-date Information]]: 최신 정보 유지
- [[Hallucination Reduction]]: 환각 감소
- [[Knowledge Integration]]: 지식 통합
- [[Cost Effective]]: 비용 효율
- [[Scalable]]: 확장 가능
