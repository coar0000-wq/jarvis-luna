### 2️⃣ Optical Character Recognition (OCR) ⭐⭐⭐⭐⭐

| 항목 | 설명 |
|------|------|
| **기능** | 고급 광학 문자 인식 |
| **정확도** | 98%+ (명확한 텍스트) |
| **속도** | 페이지당 1-3초 |
| **언어** | 100+ 언어 |
| **특징** | 회전, 기울임, 노이즈 처리 |

**OCR 강점:**
```
전통 OCR vs Claude Vision OCR

전통 OCR:
- 명확한 텍스트만 가능
- 복잡한 레이아웃 실패
- 후처리 필수
- 비용 높음

Claude Vision OCR:
- 어려운 조건에서도 추출
- 복합 문서 이해
- 의미있는 구조 제공
- 낮은 비용
```

**처리 대상:**
- 스캔된 문서
- 사진 찍은 증명서
- 손글씨 필기
- 테이프/라벨 텍스트
- 표지판 및 간판

시간: 즉시 (자동화)

비용절감: $9,985 (99.85%)
