# graph.json 검토 및 공유

이 파일은 Obsidian 그래프 보기 설정이다. 지식 노드·관계·상품 사실·에이전트 작업 지시를 담은 그래프 데이터가 아니다.

## 적용 판단

전달받은 JSON을 파싱해 저장소 `obsidian/JARVIS_LUNA/.obsidian/graph.json`과 구조·값을 비교했다. 변경 키는 0개이며 색상 그룹은 양쪽 모두 29개다. 현재 설정과 동일하므로 중복 덮어쓰기를 하지 않는다. 실제 열린 Obsidian 앱의 로딩 상태를 확인한 것은 아니다.

원문은 `docs/learning/materials/2026-10-18/graph.json`에 보존하고 공통 문서 인계의 해시 검증 대상으로 추가한다. 기존 5개 설계 문서도 그대로 유지한다.

## 설정의 의미

- 검색 필터는 `Knowledge/Records`, `Personal/templates`, `.trash`를 그래프 보기에서 제외한다. 파일 삭제나 수집 제외 명령이 아니다.
- 미해결 링크와 고립 노드는 현재 보기에서 숨긴다. 지식의 누락·단절이 해결됐다는 뜻은 아니다.
- 29개 색상 그룹은 팀·상품·지식·개인 자료·개념 등의 표시 분류다. 상품 등록 완료/오류 색상과 연결하지 않는다.
- 태그·첨부파일·화살표 표시를 끄고 노드 크기·간격·배치 힘을 설정한다. 이 설정은 팀 권한·상품 점수·승인·판매 가능성을 바꾸지 않는다.

## 검토 과제

일부 Concepts 그룹에는 두 주제 묶음이 공백(AND)으로 연결된 조건이 있다. 잘못된 조건인지 의도적인 교집합인지는 전체 노트의 실제 매칭 결과가 필요하다. 이번에는 의도 확인 없이 OR로 바꾸거나 삭제하지 않는다. 기존 `scripts/obsidian_graph_groups.py`가 제공하는 측정 경로를 사용하며, 설정 파일만 보고 실제 그룹별 노트 수나 시각적 품질을 검증했다고 하지 않는다.

## 팀 및 REA 인계

11팀에는 분류 색상과 업무 진행 상태를 혼동하지 않는다는 공통 지침을 공유한다. graph/design/knowledge 팀은 표시 설정과 실제 노트 관계를 분리해 관리한다. REA에는 UI 설정 참고 자료로만 전달하며 바이너리 분석·코드 실행·새 권한 부여 대상이 아님을 명시한다. 공유 상태는 저장소 전달이며 수신 확인이나 분석 실행 증거가 아니다.
