# 팀 공통 재사용 작업 양식

근거: [9개 영상 검토](2026-10-17-nine-videos.md). 복사해서 빈 칸을 실제 자료로 채운다. 빈 칸은 미확인 상태다. 이 문서는 특정 서비스의 스킬 설치나 실행 권한을 부여하지 않는다.

## 공통 지침

목표, 입력 파일, 출력 경로, 사실의 출처, 완료 검사, 실패 시 처리 순서로 작업을 시작한다. 관찰 사실과 해석을 분리한다. 여러 지침을 조합할 때 제품 사실·법률·예산의 기존 제한을 우선한다. 자료가 없으면 추정값을 채우지 않고 필요한 항목을 남긴다. 작업 완료와 결과 검증 완료를 구분한다.

먼저 조사 보고서를 만든 뒤 시안을 만든다. 화면이 예뻐진 것을 전환율 향상으로 기록하지 않는다. 실제 고객사 로고·후기·인증은 검증된 것만 쓴다. 참고자료의 숫자가 많다는 이유로 개별 자료의 적합성을 생략하지 않는다.

## 이미지·영상 제작 비용 기록

| 장면 | 원본 제품 이미지 | 모델/버전 | 해상도·길이 | 단가 확인일/출처 | 예상액 | 예산 | 실비 | 재시도 | 결과 파일 |
|---|---|---|---|---|---|---|---|---|---|
| 미정 | 미확인 | 미정 | 미정 | 미확인 | 미확인 | 미승인 | 미확인 | 0 | 없음 |

정지 이미지의 라벨·색·용량·형태를 원본과 비교한 뒤 영상화한다. 자막·컷 길이·전환 수정은 기존 결과물을 편집하는 것으로 먼저 해결한다. 생성 실패가 항상 무료라고 가정하지 않는다. API 키를 문서·Git·출력에 적지 않는다. 이 양식 작성은 결제나 공개 판매 승인이 아니다.

## 모델·Jev·로컬 AI 평가

`scripts/evaluate_model_replay.py`는 외부 API를 호출하지 않는다. 실제 수집 사례 30건 이상에 독립 정답을 붙인 후 기존/후보 모델을 같은 조건으로 실행해 다음 JSON을 채운다. 아래는 형식 설명이며 실제 벤치마크가 아니다.

```json
{"cases": [{"id": "실제-고유-ID", "source": "실제 기록 경로 또는 URL", "holdout": true,
"expected": null, "baseline": null, "candidate": null,
"baseline_ms": null, "candidate_ms": null, "baseline_cost": null, "candidate_cost": null}]}
```

```sh
python scripts/evaluate_model_replay.py real_cases.json --output replay-result.json
```

null은 채워야 할 측정값이며 0으로 바꾸어 성공시키지 않는다. source/holdout 표시는 제출자의 주장으로, 데이터 담당자가 실제 출처와 학습셋 중복 여부를 따로 확인한다. 현재 비교기는 정확 일치가 필요한 분류/구조화 출력용이다. 자유 서술·영상 품질의 평가에는 별도 기준이 필요하다. 모델 버전·프롬프트 해시·양자화·장비·문맥 길이를 실행 기록에 붙인다. 소비 전력과 장비 감가 비용은 API 비용과 별도로 계산한다.

## 팀별 전달

- sourcing / legal: 제품 사실·권한·unknown 검증. 모델 확률은 승인 근거가 아니다.
- pricing / channels: 실비·재시도·예산 기록과 기존 공개 게이트 유지.
- design / listing / market: 레퍼런스 조사→브리프→시안→실물/모바일 QA.
- knowledge / institutions / robotics / graph: 모델·도구 공식 출처와 버전 확인, 실제 정답셋 비교, 사실·추정·미확인 분리.
