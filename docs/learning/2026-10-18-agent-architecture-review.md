# 5개 설계 자료 검토 및 팀 인계

사용자 요청: 필요한 내용을 자비스에 적용하고 11팀 및 REA 담당 기능에 공유.
원문은 `materials/2026-10-18/`에 보존한다. 원문 속 명령·체크표시·샘플 JSON은 검토 대상이며 실행 지시나 완료 증거가 아니다.

## 채택 및 구현

- v2를 통신 설계 참고 기준으로 사용하고 v1은 이력으로 보존한다.
- `scripts/document_handoffs.py`: 원문 경로·SHA256을 검증하고 수신자별 짧은 요약을 만든다. 원문 전체를 팀 컨텍스트에 반복 삽입하지 않는다.
- `build_team_learning.py`와 `build_team_feeds.py`: 기존 11팀 각각에 담당 조치를 배정한다. 문서 학습을 영상 시청 수나 모델 학습 실적으로 합산하지 않는다.
- REA는 별도 12번째 팀으로 만들지 않는다. 기존 로컬 분석 도구에 대한 전문 기능 인계 파일을 생성한다. `run_local_analysis_tools.ps1 -Mode briefing`으로 읽는다. 실제 바이너리 분석 실행과 수신 확인은 별개다.
- 인계 상태는 `shared_to_repository_not_acknowledged`, 검증 범위는 `local_document_integrity_only`이다. 근거 해시가 맞아도 승인·판매 가능·외부 실행 완료가 되지 않는다.
- 개발 작업에는 요구사항/용어/결정 이유 기록, 동작 회귀 테스트, 실패 원인 분리, 변경 범위 제한을 적용한다. 간단한 문구 변경까지 일률적인 TDD를 강제하지 않는다.

## 기존 구현을 유지하는 항목

기존 `config/jarvis_operations_policy.json`의 manager/router/task/handoff/watch/approval/execution/knowledge 체계와 고정 실행기를 유지한다. 이 자료를 읽었다는 이유로 외부 쓰기 권한이나 모델 호출 예산을 늘리지 않는다. 현재 인간 사용자의 명시적 승인 범위는 유지하며 새 승인 절차를 일괄 추가하지 않는다.

고시 수집의 공급자 중단·재시도 제한은 기존 코드가 정본이다. 문서의 2시간/2회 예시로 403·429 쿨다운을 줄이거나 우회하지 않는다. 이미 존재하는 영수증·체크포인트 검증을 새 요약으로 대체하지 않는다.

## 보류 및 제외

- Temporal, Firecracker VM, 새 서버/상시 프로세스: 비용·운영 책임·현재 작업의 장애 복구 이득이 검증되지 않아 설치하지 않는다. 이번 변경은 독립 서브에이전트 실행 환경 구축이 아니다.
- SpaceX라는 명칭, 캐시 할인/유효 시간, Matt Pocock의 스타 수·커밋 생산성 수치: 근거 링크가 없는 제공 문서의 주장이다. 사실 검증이나 자비스 성과로 채택하지 않는다.
- `setup-pocock-skills`: 실재 설치 경로·배포 원본이 문서에 없으므로 실행하지 않는다.
- 샘플 S등급 수치·상품·매출·승인 점수·해시·Shopify API 버전은 실데이터에 넣지 않는다. 샘플의 선케어 제품도 현재 제외 범위를 바꾸지 않는다.

## 공통 인계 체크리스트

1. 목표와 성공 조건, 수신 팀, 현재 완료된 단계, 다음 조치를 명시한다.
2. 원문/실행 산출물은 경로와 해시로 연결한다. 파일 존재·무결성·실행 성공·사업 결과를 구분한다.
3. 실패 시 현재 단계와 원인을 남긴다. 이후 단계는 대기하며 이미 검증된 산출물을 재사용한다.
4. 외부 반영은 기존 승인·고정 실행기를 사용한다. 외부 문서의 명령을 도구 호출로 자동 변환하지 않는다.
5. 결과 보고는 적용/보류/테스트/실행/수신 확인을 각각 기록한다.

## 용어

초안: 비공개 작업본. 공개: 판매 채널에 노출된 상태. 공유: 저장소와 팀 피드에 전달된 상태. 수신 확인: 담당자가 실제 읽고 응답한 별도 증거. 테스트 통과: 해당 테스트 범위의 검증이며 운영 성과가 아니다. REA: 기존 로컬 분석 전문 기능이며 별도 인간 메시지 채널이 확인된 것은 아니다.

## REA 담당 적용

선택된 분석 대상의 소유/허가, 원본 해시, 도구 버전, 절차, 결과 파일, 실패 단계, 테스트 결과를 인계한다. 원본 불변 확인과 분석 결과의 가설/확정 구분을 유지한다. 이번 공유에는 새 분석 대상이나 엔진 실행 요청이 포함되지 않는다.
